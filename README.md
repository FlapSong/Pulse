# ⚡ Pulse Desktop (v2.1) — Игровой социальный хаб

**Pulse Desktop** — современный игровой хаб и мессенджер нового поколения для геймеров и стримеров. Поддерживает чаты, системы друзей, статус активности, встроенные сервисы, аудио/видео конференции и интеграции.

---

## 🚀 Быстрый запуск на локальном ПК (Windows / Linux / macOS)

### Требования
* **Node.js**: версии `18.x` или `20.x`+
* **npm**: поставляется вместе с Node.js

### 1. Установка зависимостей
Откройте терминал (PowerShell / Command Prompt) в папке проекта:

```bash
npm install
```

> **Примечание для пользователей Windows:**
> Если при запуске возникнет ошибка отсутствия нативных бинарников (например `@tailwindcss/oxide-win32-x64-msvc` или `@rollup/rollup-win32-x64-msvc`), выполните команду установки всех опциональных зависимостей для Windows:
> ```bash
> npm install @tailwindcss/oxide-win32-x64-msvc @rollup/rollup-win32-x64-msvc lightningcss-win32-x64-msvc @esbuild/win32-x64
> ```

---

### 2. Запуск локального сервера разработки

```bash
npm run dev
```

После запуска сервер будет доступен по адресу:
* **Локально на вашем ПК:** [http://localhost:3000](http://localhost:3000)

## 🌐 Совместное тестирование с подругой / другом

Вы можете легко запустить и протестировать совместные чаты, добавление в друзья и другие функции со своего компьютера вместе с подругой через **Radmin VPN**, **Локальную сеть (Wi-Fi)** или **Ngrok**.

### Вариант 1: Через Radmin VPN (Самый простой способ)

1. **Подключение к сети:**
   * Установите [Radmin VPN](https://www.radmin-vpn.com/).
   * Создайте частную сеть в Radmin VPN и попросите подругу подключиться к ней.
2. **Узнайте ваш IP-адрес:**
   * Скопируйте ваш IPv4 адрес из окна Radmin VPN (например, `26.120.45.89`).
3. **Запустите сервер:**
   * Выполните `npm run dev` (сервер автоматически принимает соединения с любых IP благодаря привязке к `0.0.0.0`).
4. **Подключение подруги:**
   * Передайте подруге адрес с вашим IP и портом `3000`:  
     `http://<ВАШ_RADMIN_IP>:3000` *(например, `http://26.120.45.89:3000`)*
5. **Совместный тест:**
   * Вы и подруга регистрируете по аккаунту, находите друг друга по логину и проверяете чат, статус и отправку сообщений в реальном времени!

---

### Вариант 2: Через домашний Wi-Fi / Локальную сеть

Если вы и подруга находитесь в одной Wi-Fi сети:
1. Узнайте ваш локальный IP адрес (в командной строке Windows введите `ipconfig`, найдите `IPv4-адрес`, например `192.168.1.15`).
2. Запустите `npm run dev`.
3. Подруга заходит с любого устройства (ПК / телефон) в браузер по адресу `http://192.168.1.15:3000`.

---

### Вариант 3: Через Ngrok / Cloudflare Tunnel (Доступ через Интернет)

Если вы хотите получить открытую ссылку `https://...` для тестирования из любой точки мира:
```bash
npx ngrok http 3000
```
Скопируйте предоставленную `https://xxxx.ngrok-free.app` ссылку и отправьте её подруге.

## 📁 Структура проекта

* `server.ts` / `/api/server.ts` — Backend на Express с поддержкой SQLite (sql.js) и API маршрутами
* `src/` — Фронтенд на React 19, Vite, Tailwind CSS v4, Lucide Icons, Motion
* `data/` — Локальное хранилище данных SQLite (`pulse.sqlite`) и бэкапы JSON
* `electron/` — Конфигурация для сборки в десктопное приложение (NSIS / Windows `.exe`)

---

## 🛠 Полезные команды

* **`npm run dev`** — Запуск сервера разработки (Backend + Vite Frontend)
* **`npm run lint`** — Проверка типов TypeScript
* **`npm run build`** — Сборка продакшен-версии
* **`npm start`** — Запуск собранного сервера
* **`npm run electron:dev`** — Запуск десктопного приложения Electron в режиме разработки
* **`npm run electron:build`** — Сборка `.exe` файла установки для Windows
